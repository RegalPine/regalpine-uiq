# UIQ Diagnostics

Diagnostics explain Findings.

## Principle

Diagnostic != Evaluation

Diagnostic != Recommendation

## Evidence Graph

DOM
↓
Measurement
↓
Metric
↓
Rule
↓
Evaluation
↓
Finding
↓
Diagnostic

## Root Cause

Possible causes:

- MEASUREMENT
- METRIC
- TOKEN
- COMPONENT
- THEME
- CONFIGURATION
- UNKNOWN

## Confidence

- DIRECT
- SUPPORTED
- INFERRED
- UNKNOWN

Do not invent a root cause when evidence is insufficient.
