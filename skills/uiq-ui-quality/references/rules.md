## Rule Result

A Rule produces an Evaluation.

Possible states:

PASS
FAIL
WARN
NOT_APPLICABLE
UNKNOWN
ERROR

## Important

Metric:

"contrast = 4.48"

Rule:

"contrast >= 4.5"

Evaluation:

"FAIL"

Do not combine these concepts.
